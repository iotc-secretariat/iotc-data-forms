## Changes

- Restructured the data worksheet from a wide format to a tabular format, with one price observation per row  
- Replaced Month with Date start and Date end  
- Added Species and Product type as individual columns  
- Added Price type, Price calculation method, and Price columns  
- Removed Processing, Preservation, Weight unit, Weight class (lo), and Weight class (hi)  
- Retained Pricing location, Currency, and Destination, with columns reordered  
- Reorganised the worksheet into Main elements and Price elements
